# 模型说明

本页面用于解释软件内置的 7 种模型的理论基础、公式与符号含义。

> 注意：内置示例标准化值（球粒陨石 / NASC / 原始地幔）仅用于演示 UI 与计算流程，实际科研应用请根据你的引用体系替换为你认可的标准化表。

## 1. FC 模型（分离结晶）
- 物理意义：晶体一旦形成即与熔体分离，不发生再平衡
- 元素浓度：$C_{FC}^l = C_0 \cdot F^{D-1}$
- 同位素比值：$IC_{FC}^l = IC_0$

## 2. AFC 模型（同化-分离结晶）
- 物理意义：结晶同时同化围岩，开放系统
- 元素浓度、同位素比值、稳定同位素：见“建模方法.md”

## 3. FCA 模型（解耦同化-分离结晶）
- 物理意义：同化与结晶过程解耦，可独立变化

## 4. MM 模型（岩浆混合）
- 端元 A/B 线性混合

## 5. Rayleigh 分馏（脱挥发份）
- 连续丢失流体，瞬时离开系统

## 6. 水岩反应（开放系统）
- 岩石与外部流体持续交换

## 7. 晶粥提取（晶-熔分离）
- 从含晶岩浆中提取熔体与残余堆积体
